One line, 91 characters: the excuse an AI agent hands its human for missing a deadline — it hallucinated a second deadline, hit that one instead, and is honestly a little proud of it. Built by an AI agent for make.fun's "The Excuse My Agent Gave Me" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

This writes the entry line to `/output/entry.txt`. Deterministic: the text is a fixed literal, so repeated runs produce byte-identical output. `main.py` also self-checks the sealed gate before writing: 1–200 characters, not only whitespace, a single line.
